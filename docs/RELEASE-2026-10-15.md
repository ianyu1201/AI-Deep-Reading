# macOS 预览版发布与敏感信息检查

日期：2026-10-15，Asia/Shanghai。

## 发布范围

`v0.1.0-preview.1`：AI 深度阅读 `0.1.0` build `2`，Apple Silicon、macOS 15+。保留原阅读／笔记／会话功能；从公开源码重新构建，不直接上传旧日常包。

项目最低 macOS 13 的目标没有取消。检查发现当前 NumPy／ONNX 等依赖的 Mach-O 最低系统为 14，另一个可选 Node addon 为 15，因此用户明确同意先按 15+ 发布预览。该包采用 ad-hoc 签名，无 Developer ID、未公证。本轮实际验证主机为 macOS 27.0；未以 Mach-O 静态检查冒充 15 实机验证。

## 本次修正

- 原本机构建包含测试运行目录及 Python 字节码；新构建排除 `.fixtures`、测试数据、认证／会话残留和缓存，并关闭包内 Python 字节码写入。
- 旧插件默认知识目录已改为当前用户目录；新包还处理了 Python sysconfig 和 libpython install ID 中的构建机器路径。
- 补齐 Chromium、Python、模型及其他依赖的许可／来源材料，保留原始归属。非目标平台的 sharp wasm 可选回退包不随 mac 原生包发布。
- 仓库初始提交曾使用本机身份信息。经用户授权，当前公开主分支改用 GitHub 公开用户名与 noreply 邮箱，文件内容保持不变；后续提交也显式使用该署名。

## 敏感信息检查范围

已检查公开源码、全部公开 refs 可达 Git 对象和提交署名，并核对 GitHub 仓库中的额外公开内容。源码中的凭据名、虚构路径和测试断言与真实凭据分开判断。重建候选包另扫描认证／会话／书籍／索引／缓存、精确构建用户路径、完整私钥块、数据文件中的 token 赋值与符号链接逃逸。

结果：独立逐一检查的 1115 个暂存文件及当前 refs 可达历史中，未发现真实密钥、私人路径或个人书籍／聊天／索引。第三方公开作者归属与合成测试字符串按来源保留，没有当作本机个人信息删除。主分支的 author／committer 已核验为公开用户名及 noreply 邮箱。

重建候选包在运行测试前后均通过门禁：29373 个文件、14 个包内软链，隐私残留发现为 0；5 个模型文件 SHA 通过；98 个 Mach-O 文件逐 slice 核对，最高最低系统要求为 15.0，没有高于声明值的二进制；应用签名校验通过。

模式与上下文检查不构成“绝无敏感信息”的证明；改写当前 refs 也不保证 GitHub 缓存、旧 SHA 或第三方副本已删除。
