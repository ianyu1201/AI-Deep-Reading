# macOS preview.2：第一轮安装包瘦身

日期：2026-10-15，Asia/Shanghai。本文是本轮独立记录，不修改 `preview.1` 的历史结论。

## 范围与版本

目标 tag：`v0.1.0-preview.2`；应用版本 `0.1.0`，build `3`；Apple Silicon、macOS 15+，ad-hoc 签名、未公证。macOS 13 仍是项目目标，不是本次安装包已经通过的最低系统。

本轮通过显式 `--slim` 只裁剪发布负载，保留 Python 运行时与语义模型、Codex、Node、Electron，以及阅读、笔记和 AI 会话依赖的现有入口。不带此开关仍可构建完整负载作对照。没有授权新增业务功能或更改模型协议。

## 裁剪规则

- 未启用的 LibreOffice 平台负载：省略 `bin/`、`program/`，保留包元数据、JavaScript 包装入口及 `licenses/`、`sources/`。
- 未启用的语音平台负载：省略 sherpa 平台 `.node`、`.dylib`；保留语音相关 JavaScript 入口、包元数据和许可材料，避免破坏 SDK 静态导入。
- 通用文档预览：省略约定的三个客户端浏览器 bundle，保留 Host 入口。精确路径以裁剪清单为准；不将阅读器的 EPUB／Markdown 功能纳入裁剪。
- node-pty：保留 `darwin-arm64` 预编译，省略其他平台／架构预编译及 Windows `third_party/conpty`。
- 省略 `node_modules` 中的源映射 `.map`，保护许可／版权声明目录。运行代码和许可证不会因扩展名规则一起删除。源映射减少后，依赖代码的调试定位能力会相应降低。

这些是本轮规则；最终实际省略路径、文件数和字节数以候选包的机器清单为准，不能用规则文字替代结果验收。

## 第三方声明与源码附件

第一方代码继续为 MIT；实际保留的第三方组件各按其许可分发。许可目录保留已经省略的办公／语音组件声明作为来源归档，不代表本包仍携带它们的原生二进制。`preview.1` 中 sherpa／eSpeak GPLv3 负载的历史记录保持不变。

本轮复用 `AI-Deep-Reading-0.1.0-third-party-sources.tar.gz`，并在新 Release 原样附上，使下载者在同一发布页面取得材料，无需另行安装。这份来源资产包含原生 libvips／sharp 的精确版本、构建脚本、补丁、对应源码及 librsvg crate 来源，也保留不再随包带二进制的 sherpa／eSpeak 来源超集。
