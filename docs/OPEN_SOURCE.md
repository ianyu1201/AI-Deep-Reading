## 来源与版本

本仓库从独立 macOS 客户端工作区的当前源码建立新历史。旧插件上游为 `ianyu1201/DSH-apple-Read`；导入前工作区基线提交为 `0aa499c`，桌面新增代码当时尚未提交，因此该旧提交不是本客户端的完整版本。

对应的本机应用标识为 `0.1.0`（build 1），开发 package 版本为 `0.1.0-dev.1`。发布准备时核对了当前应用、最新本机构建记录与第一方源码；该构建记录的 338 项哈希与应用一致。样书 catalog 在打包时按规则置空。

公开副本仅做以下适配：

- 把旧插件知识库默认值从特定用户名绝对路径改为当前用户的 `Documents/AI-knowledge/45-书籍`；桌面运行时继续显式注入应用私有目录。
- 移除样书／封面，以空 catalog 启动；对应测试改为检查空书库，原生冒烟测试使用可生成的原创 EPUB。
- 整理 README、构建与测试入口，排除依赖本机文档、凭据或真实书籍的历史验收脚本。
- 既有导读取消测试将初始化保存和取消收尾混入同一事件序列；公开副本单独断言初始化保存，再验证取消、异步清理与最终保存，业务逻辑未改。
- 保留原有许可、第三方代码及其本地修改；不迁入原工作区的 Git 历史或个人运行材料。
